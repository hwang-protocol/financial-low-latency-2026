## 2026-09-12 · 运行④直接对照 CPU 分配与执行竞争

原图只复述“跟上一步改了什么”，无法看出共享CPU的机制，现原位重绘为1200×820的两组CPU分布。蓝色订单图标表示MANUAL下单线程，浅橙线程图标表示两个Trader的其他应用线程，绿色CPU3固定放AUTO下单线程。两组同为SPSC忙轮询；左侧MANUAL单独在CPU2，右侧与其他应用线程共用CPU0。

底部色带只示意应用线程在同一CPU上轮流执行，不是实测时序或定量时间片；不使用网络箭头。图只列CPU0/2/3，CPU1未画出；“单独”不等于系统不可抢占或独占物理核。800/1200px整图、36处文字边界及MANUAL图标留白已检查。正文删重复椅子比喻和两张表，标题、导航、轮次标签与结果解读同步；旧输出原文保留并就近解释其名称。见[CPU分配图核验](../../../refs/evidence/chapter04-cpu-placement-visual-20260912.json)。
